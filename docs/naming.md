# Naming — one word per thing

Hero Nexus has a voice, and the voice was costing it findability. The same idea wore
four names ("Sittings", "Chronicle", "Session", "the evening"), and four different
ideas wore the same name ("the shelf" was the library, the shop's stock, the board
list and the screen's side panels). A DM could not find the fight thing because it was
called four things.

This document is the vocabulary. It is binding: where a label in the code disagrees
with the table below, the code is wrong. The voice survives in the _margin_ — the hand
face, the empty states, the asides — which is where
[design-language.md](design-language.md) rule 5 says whimsy belongs. Load-bearing
labels are straight.

## The rule

**One thing, one name, everywhere.** A nav item, a panel title, a button, a heading
and a search result for the same thing use the same word. If two things need different
names, they are different things; if they share a name, they are the same thing.

## The verbs

| The act                                                                      | The verb                       | Never again                                               |
| ---------------------------------------------------------------------------- | ------------------------------ | --------------------------------------------------------- |
| Letting the party see a thing (quest, canon line, note, handout, token, map) | **Show the party**             | "tell them", "reveal", "hand over", "push", "show them"   |
| Taking it back (only where the model allows it)                              | Hide again                     | "take it back"                                            |
| Making a battle board the one in play                                        | **Put it in play**             | "put it on the table", "take your seats" (for a board)    |
| Taking it out of play                                                        | Take it out of play            | "take it off the table"                                   |
| Beginning an evening                                                         | **Start the session**          | "take your seats"                                         |
| Ending an evening                                                            | **End the session**            | "rise", "the table rises"                                 |
| Beginning a fight                                                            | **Roll for initiative**        | "call for initiative", "roll for it", "start a fight"     |
| Ending a fight                                                               | End the fight                  | —                                                         |
| Putting foes on the board before the fight                                   | **Place** them                 | "deal them in" (that is now only "add them to the order") |
| Pointing at a tile (alt-click, or hold a finger on it)                       | **Ping** it                    | "mark", "flag"                                            |
| Asking the DM to pause, without saying who                                   | **Tap the X-card**             | "flag", "raise the card", "X it"                          |
| Bringing a hero in from a pasted D&D Beyond character                        | **Import from D&D Beyond**     | "sync", "link your account", "convert"                    |
| Making a battle board from a .dd2vtt/.uvtt file                              | **Import a Universal VTT map** | "upload a map", "dd2vtt import"                           |
| Putting something Search found onto the Lookups panel                        | **Keep it on the screen**      | "pin", "save", "bookmark"                                 |
| Putting the party's next stop on the journey                                 | **The party is here**          | "move the party", "add a waypoint"                        |
| Putting a named point on a canon map                                         | **Mark a place**               | "drop a marker", "add a pin"                              |
| Planning the party's next stop on the journey                                | **Headed here**                | "set destination", "plan route"                           |
| Adding an NPC who lives in the place being looked at                         | **Someone who lives here**     | "add resident", "new NPC here"                            |
| Rolling a random table of names into a place's people                        | **Fill this place**            | "populate", "generate NPCs"                               |
| Bringing a struck entry back into the rolling                                | **Bring it back**              | "restore", "unstrike"                                     |
| Giving something that is not placed yet a place in the World                 | **Place it**                   | "assign", "set location", "move to"                       |
| Leaving a quest with no place, on purpose, for this visit                    | Leave it everywhere            | "ignore", "dismiss"                                       |
| Writing something new into the place being looked at                         | **Add to** _the place_         | "create here", "new in", "add here"                       |
| A player putting a rumour on a map                                           | **Mark a rumour**              | "mark a guess", "drop a pin"                              |
| Turning a player's rumour into a place, still signed by them                 | **Make it real**               | "promote", "confirm", "accept"                            |
| Sending a moment to the campaign's Discord channel                           | **Post to Discord**            | "notify", "announce", "send to Discord"                   |

"Show the party" is one verb because it is one act, and one act gets one glyph
(`candle`), one keyboard shortcut and one line in Revealed.

## Where the voice still lives

Unchanged, and deliberately: `Marginalia` asides, `EmptyState` scenes and their
copy, the dice tray's verdicts, announcement slips, and the in-world descriptions
under a heading. "no one has pulled up a chair yet" is still how an empty party reads.
What changed is that the _heading above it_ says **Party**.
